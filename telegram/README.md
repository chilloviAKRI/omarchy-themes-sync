# Telegram Desktop / AyuGram Theme Sync with Omarchy

Автоматическая синхронизация темы **Telegram Desktop / AyuGram** с активной темой дистрибутива **Omarchy**.

## Особенности
- **100% адаптация под тему Omarchy**: все фоны, панели, счётчики непрочитанных, значки статуса, аватарки без фото, карточки звонков, медиаплеер и галочки адаптируются под активную тему Omarchy.
- **Выделение текста в стиле macOS**: выделение сообщений и текста (`msgInBgSelected`, `msgOutBgSelected`) зафиксировано в системных цветах macOS (`#0063E6` для тёмных тем, `#B3D7FF` для светлых).
- **Мгновенное применение без перезапуска**: Telegram отслеживает файл `omarchy.tdesktop-theme` через inotify/QFileSystemWatcher и перезагружает цвета на лету при выполнении `omarchy theme set <название>`.
- **Автозапуск и синхронизация при загрузке**: хук `post-boot` обновляет тему при входе в систему.

## Быстрая установка

1. Распакуйте архив и запустите скрипт установки:
   ```bash
   ./install.sh
   ```
   Скрипт скопирует проект в `~/.config/omarchy/telegram-theme`, установит хуки в `~/.config/omarchy/hooks/` и сгенерирует тему под текущую тему Omarchy.

2. **Разовая активация в Telegram Desktop / AyuGram** (делается 1 раз):
   - Откройте **Настройки** -> **Настройки чатов** -> три точки в правом верхнем углу -> **Выбрать из файла**.
   - Укажите файл:
     `~/.config/omarchy/telegram-theme/omarchy.tdesktop-theme`
   *(или отправьте этот файл в Saved Messages / Избранное и нажмите «Применить тему»)*.

После этого тема будет переключаться автоматически при любой смене темы в Omarchy!

## Структура проекта
- `omarchy-telegram-theme.py` — генератор `.tdesktop-theme` из текущей палитры Omarchy.
- `install.sh` — автоматическая установка проекта и хуков Omarchy.
- `bin/sync.sh` — перегенерация темы in-place для обновления на лету.
- `bin/activate.sh` — хелпер для копирования пути к теме в буфер обмена.
- `hooks/` — хуки для `theme-set.d` и `post-boot.d`.
- `base/` — базовые палитры Telegram Desktop (`night.palette`, `day.palette`).
- `overrides.txt` — зафиксированные цвета macOS для выделения текста.
- `frozen.txt` — список защищённых ключей палитры.
